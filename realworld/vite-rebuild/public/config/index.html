Config

Configuring Vite

When running vite from the command line, Vite will automatically try to resolve a config file named vite.config.js inside the project root.

Config Intellisense

Vite ships with TypeScript typings for full editor IntelliSense.

Conditional Config

If the config needs to conditionally determine options based on command, mode or target, it can export a function.

Async Config

The config file can export a promise, allowing asynchronous config resolution.

Using Environment Variables in Config

Environment variables can be loaded with a loadEnv helper.

Debugging the Config File in VS Code

Breakpoints in the config file can be debugged with the VS Code debugger.
